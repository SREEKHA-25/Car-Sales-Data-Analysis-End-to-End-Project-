# 🚗 Car Sales Data Analysis

## 🔍 Project Overview
This project analyzes car sales data to understand pricing trends, top brands, and seller performance.

## 📁 Dataset Features
- Year, Make, Model
- Transmission, Body Type
- Seller Information
- Selling Price & MMR
- Odometer (mileage)

## 🛠 Tools Used
- Excel → Data Cleaning
- SQL → Data Analysis
- Python → Data Visualization
- Power BI → Dashboard

## 📊 Key Insights
- Identified brands with highest average selling price
- Found top sellers in the market
- Compared MMR vs Selling Price
- Analyzed impact of mileage on price
